# ⚡ Greedy Algorithms – Algorithm Design Project

## 📌 Project Overview
This project focuses on implementing and analyzing various **Greedy Algorithms**.  
Greedy algorithms work by making a series of **locally optimal choices**, hoping to reach a **globally optimal solution**.  
They are widely used in optimization problems due to their simplicity and efficiency.

---

## 💡 Key Features
- 🔁 **Greedy Choice Property**: At each step, the algorithm selects the best option available at that moment.
- 🧩 **Optimal Substructure**: The global optimum can be built from solutions of its subproblems.

---

## 🧠 Algorithms Implemented
- 🕒 **Activity Selection Problem**
- 🧬 **Huffman Coding**
- 🎒 **Fractional Knapsack Problem**
- 🌲 **Minimum Spanning Tree (Prim’s Algorithm)**
- 🧾 **Job Sequencing with Deadlines**
