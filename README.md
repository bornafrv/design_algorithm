# 📐 Algorithm Design Collection

Welcome to my **Algorithm Design** project repository. This repo contains categorized implementations of fundamental algorithmic paradigms covered during the course at **University of Tehran**.  
Each category includes solved problems, Python implementations, and PDF problem statements.

---

## 📁 Folder Structure

| Category               | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| 🔀 **Divide & Conquer** | Recursive algorithms like Merge Sort, Quick Sort, Binary Search, etc.       |
| 💡 **Dynamic Programming** | Memoization-based solutions like LCS, Knapsack, Matrix Chain, Edit Distance |
| 🌐 **Graph Algorithms**    | Traversals (BFS/DFS), shortest paths (Dijkstra, Bellman-Ford), MST, etc.   |
| ⚡ **Greedy Algorithms**   | Greedy solutions like Activity Selection, Huffman Coding, Fractional Knapsack |
| 🧩 **NP-Complete**         | TSP, Hamiltonian Path, Vertex Cover, Graph Coloring with heuristics        |
